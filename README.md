
Wormtongue's Professions 

## Currently implemented features

* Shows your professions and secondary skills.
* Shows current skill / maximum skill.
* Skill numbers change color based on progression.
* Automatically updates when your skills change.
* Movable and resizable window.
* Close button.
* Handles 1–3 digit skill levels without overlapping.

## How to Open

Currently use:

/run wp()

This opens and closes the profession window.

## Installation

1. Download the addon.
2. Extract the `WormtongueProfessions` folder.
3. Place it in: AddOns folder 

 Type /run wp() in chat.
 make a /macro for ease of use

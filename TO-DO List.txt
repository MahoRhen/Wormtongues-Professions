# RULE FOR FUTURE DEVELOPMENT

Do not add major features directly into large existing functions.

When a system becomes complicated:

* [ ] Identify the responsibility
* [ ] Move it into its own function/module
* [ ] Keep data separate from UI
* [ ] Keep UI separate from logic
* [ ] Keep reusable systems reusable

Wormtongue should grow as a collection of small systems rather than one giant Lua file.
